# Default avatar

Put your default avatar image here as `default-avatar.jpeg`.

It is shown when a user has no Google profile picture, or when their picture
fails to load. Square, at least 128×128 so it stays crisp on retina screens.

Using a different filename or format (`.svg`, `.webp`) is fine — update
`DEFAULT_AVATAR_SRC` in `src/components/ui/avatar.tsx` to match.
